# Contributing to Awesome Bitcoin Culture

Thanks for helping grow this list. A few ground rules before opening a PR or issue.

## What belongs here

See [What belongs here](README.md#-what-belongs-here) in the README. Short version: good creative
work about Bitcoin, by someone you can name (memes excepted), with a portfolio, site or page that
shows the work.

## How to submit an entry

Prefer a guided submission? [Use the suggestion form on the gallery](https://awesomebitcoinculture.com/#suggest), which checks for duplicates and opens a pre-filled GitHub issue, or [open the GitHub issue form directly](https://github.com/itstomekk/awesome-bitcoin-culture/issues/new?template=suggest-entry.yml). For a direct pull request, use the checklist below.

1. Open a PR or an issue with:
   - Name of the creator/work.
   - One-line description of the medium and what makes it notable.
   - A working link where the work can actually be seen (not just a social profile with no
     visible work).
2. Add it to the right section, alphabetically or chronologically as the section already does.
3. Keep the one-line format consistent with existing entries — no marketing copy.

## What gets rejected

- Financial products, exchange marketing, speculative collectible drops, meme coins.
- Dead links or abandoned stubs.
- AI-majority art, on hold for now. AI as one part of hands-on work, or AI used as an art form
  (such as a film made by directing many AI tools), is welcome when it shows real craft and the
  artist has a portfolio. Say so in the entry.

## Style

- One bullet per entry, bolded/linked name first, then a short description.
- No emoji, no ALL CAPS, no superlatives ("the best", "must-see").
- If unsure whether something fits, open an issue to discuss before a PR.
